# 用语与文风规范

本文件是「经纬纵横」全部对外文字的写作依据，适用于页面标题、导语、说明、图注、表注、结论与研究报告正文。
规范的目的不是让文字"看起来正式"，而是让每一句话都能被研究者和政策部门直接引用。

---

## 一、总则

1. **语料是标准，不是素材。** 求是、人民日报、经济日报、光明日报的经济报道与评论，用于确认"这类内容在规范汉语中怎么表述"，不用于摘句拼装。禁止从语料中截取短语重新组合成句。判断标准只有一条：写出来的每一句，都应当是独立的、通顺的、可以脱离上下文单独成立的汉语。

2. **不造词。** 一个词若不能在三类来源中找到既有用法，即视为造词，不得使用：
   - 政策文件原文（如"跨周期调节""直达机制""以旧换新"）；
   - 统计与计量标准术语（如"同比""环比""中位数""置信区间""样本量"）；
   - 学科教材与权威辞书（如"传导渠道""时滞""结构性因素"）。

3. **自设指标必须用既有构词法命名，并给出定义。** 可用"××指数""××系数""××比率""××强度"；不得使用语义模糊、靠上下文才能猜出含义的名称。定义在首次出现处给出，一处定义，全文一致。

4. **不自我评价，不自我辩护。** 说明方法与范围时只陈述事实：写"观察范围为 8 个地方单元"，不写"本报告最需要克制的一节"。

---

## 二、句式

| 要求 | 说明 |
| --- | --- |
| 判断句、陈述句为主 | 每段第一句给出结论，其后给依据。不用设问句开头，不用"是不是""能不能"作段落骨架。 |
| 不用第二人称 | 不出现"你""您""你们"。面向读者的说明改为无主句或"读者"以外的表述。 |
| 慎用第一人称 | "本报告""本文""本平台"可作主语；不用"我们觉得""我们认为"（研报惯例可用"我们判断"，但全文不超过三次）。 |
| 慎用破折号 | 正式文本以顿号、分号、括号承担停顿与注释功能。破折号每千字不超过一处。 |
| 不用口语连接 | 禁用"其实""说白了""反倒是""也就是说""也就是说""反过来""宁可""不然""搞""弄"。规范连接词：从……看、分领域看、总体看、与此同时、另一方面、据此、由此。 |
| 不用比喻与拟人 | 禁用"地方什么时候动""谁接了""大片空白""跑通""落地开花"。改为"地方跟进时点""跟进情况""未匹配"。 |
| 句中不插入元评论 | 删去"这一张图回答……""读法是这样""最容易犯的错"。图注只写：图名、变量含义、样本范围、数据来源。 |
| 一句话一个判断 | 单句不超过 60 字；超过则拆分为两句。定语不超过两层。 |

## 三、数据表述

1. 数字必须带单位与口径：写"中位时滞 16 天"，不写"中位 16"；写"近 90 天公开政策类文件 215 份"，不写"215 份文件"。
2. 比例写"占比 X%"或"X 组，占 Y%"，同类指标全文只用一个写法。
3. 区间用"至"或"—"：写"31—60 天""2026 年 7 月 31 日至 10 月 20 日"。
4. 增减用"较……上升／下降 X 天／个百分点"，不用"多了""差了"。
5. 样本量在结论中必须出现。凡涉及比较的句子，同句内给出分母。

## 四、禁用表述与规范表述对照

| 禁用 | 问题 | 规范表述 |
| --- | --- | --- |
| 一键研判 / 不用你搜 | 营销语、第二人称 | 政策扫描 / 系统自动检索官方栏目 |
| 政策证据工作台 | 自造机构名 | 宏观政策研究平台 |
| 暴露度 | 语义不明 | 影响强度 |
| 疑似承接 | 自造状态名 | 相关文件（正文相关、标题未命中） |
| 可判配对 | 自造 | 有效样本 / 可判定组合 |
| 质量体检 / 编码抽检 | 内部审核用语 | 不对外呈现 |
| 方法与边界 / 能回答什么、不能回答什么 | 自我辩护式结构 | 观察范围 / 数据说明 |
| 这不是全国样本，先把边界说清楚 | 口语 + 元评论 | 本页观察范围为 8 个地方单元 |
| 读起来不够顺，是因为没有替原文补话 | 元评论 | 摘要取自原文，未作补充 |
| 宁可少画一个省，也不把空白当成"地方没做" | 口语 + 表态 | 未接通栏目不计入统计 |
| 答辩时不必临场找补 | 场景化口语 | （删除） |
| 踩坑 / 跑通 / 兜底 / 拆成 | 工程口语 | 出现问题 / 验证通过 / 备用 / 分解为 |
| 讲清 / 说清 / 搞明白 | 口语 | 说明 / 明确 |
| 事实与推断分开 | 可保留，但避免作为宣传语反复出现 | 标注来源与推断程度 |

## 五、标题与栏目命名

- 一级标题用"对象 + 动作"的名词化结构：政策扫描、省级影响评估、央地传导观察、研究报告。
- 二级标题用"发现一：……""一、……"，不用问句、不用比喻。
- 图表标题格式：**图 N　名称（样本或单位）**；表标题格式：**表 N　名称（口径）**。
- 英文栏目名仅作辅助标识，全大写，不使用缩写自造词。

---

## 六、交稿前自检（五条）

1. 是否出现第二人称、口语连接词、比喻？出现即改。
2. 是否出现无法在三类来源中查到的词？出现即换。
3. 每个数字是否带单位与口径？每个比较是否带分母？
4. 是否有"本节最需要……""最容易犯的错……"这类元评论？有则删。
5. 任取一段单独读出，是否通顺、是否像正式出版物的一节？不通顺则重写，不得靠加词修补。
