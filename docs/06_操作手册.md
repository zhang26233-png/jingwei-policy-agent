## 一、加一个新主题锚点

**场景**：想让央地传导多观察一个政策领域。

**改哪里**：`src/lib/transfer.ts` 的 `THEMES` 数组，追加一项。

**五项必须都填**，缺一项会静默出错：

```ts
{
  id: 'carbon-market',                    // 唯一标识，不要和已有的重复
  theme: '全国碳市场扩围',                  // 页面显示的完整名
  short: '碳市场',                         // 矩阵和排行里的短名，≤5 字
  centralTitle: /全国碳市场/,               // 到中央语料标题里找这份文件
  centralDate: '2026-09-15',               // 找不到时的兜底日期，必须以原文标注为准
  keys: /碳市场|碳排放权|碳配额/,           // 地方标题匹配
  why: '扩围涉及地方配额分配与核查机构，省级需要配套文件。',
}
```

**三个常见的错**：

| 错法 | 后果 |
|---|---|
| `keys` 写太宽（如只写 `/碳/`） | 大量无关文件命中，`respond` 虚高，中位时滞被压短 |
| `centralDate` 随手填 | 找不到中央文件时会用这个日期算时滞，整个主题的结论全错 |
| `why` 不写或写套话 | 半年后没人知道为什么选这个主题，容易被当成随便加的 |

**改完必看**：

```bash
npm run build
node -e "..."   # 或用 .tmp/verify.mjs 看一下 respond 数和分档有没有异常跳变
```

如果 `respond` 从 7 一下涨到 15，十有八九是 `keys` 太宽，回去收紧。

## 二、加一个新的地方省份

**前提**：不要凭猜测加。先跑探测，确认这个门户真能抓到政策文件列表。

```bash
node scripts/probe-provinces.mjs
```

**改哪里**：`server/locals.mjs` 里的省份定义（`list`、`name`、`short`、`level`、`kind`）和省份白名单。

**必须同时改的**：

1. **`kind` 字段要如实写这个栏目收什么**（"市政府及部门文件" / "省政府及办公厅文件"）。这个字段会显示在央地传导页的口径说明里，写错的后果是读者不知道各地口径不一致。
2. **`level` 必须用 `省级` / `市级` 开头**。代码里用 `startsWith('省级')` 判断。写成"副省级市"会被算成省级，覆盖率分母就错了。

**改完必须做的**：

```bash
node scripts/collect-locals.mjs        # 重新采集，耗时 8—12 分钟
```

然后看新省份有没有过闸门（近 90 天 ≥6 份 + 更新晚于 10-20）。**没过就让它显示"未纳入"，不要调阈值凑数。**

## 三、改可用性闸门

```ts
const GATE = { minRecentDocs: 6, minLatest: '2026-10-20' };
```

**`minRecentDocs` 只许调高或维持，不许为了凑数调低。**

实测数据摆在这里：黑龙江总条数 35、近 90 天只有 4 份；山西近 90 天 4 份。降到 4 会把它们放进来，但它们本身就不怎么更新，"没跟进"和"没发文件"分不开——这会产生大量假阴性，比样本小更糟。

**`minLatest` 是硬编码日期，必须改成相对偏移。** 见 `04_任务清单` T1。改法：

```ts
// 不要写成固定日期
const minLatest = payload.at
  ? new Date(new Date(payload.at).getTime() - 18 * 86400000).toISOString().slice(0, 10)
  : '2026-10-20';
```

## 四、加一个事务性文件排除词

`src/lib/transfer.ts` 的 `EXCLUDE_DOC`。

**加词容易**：发现某类文件被误判，加进正则即可。

**减词要谨慎**：减一个词可能让 `respond` 从 7 涨到 11，涨出来的多半是假的。减之前先跑一遍看看具体是哪几条新进来了，逐条核对。

已知的两个真实误判（注释里写着）：

- "人工智能领域颠覆性技术方向储备**课题征集**" → 曾算成 +0 天响应
- "文物保护工程**资质**单位**培训班**" → 曾算成文化遗产 +14 天

## 五、重新采集语料

### 中央语料

页面右上角「自动扫描」，或：

```bash
curl --noproxy '*' -X POST http://127.0.0.1:8787/api/collect
```

写入 `data/policies.json`。约 3—5 分钟。

### 地方语料

```bash
node scripts/collect-locals.mjs
```

写入 `data/locals.json`。约 8—12 分钟。**只有这个脚本能更新央地传导的数据**，页面上的按钮不更新它。

脚本里已把并发压到 2、请求间隔 400ms。**不要调高**——早期并发 6 时触发了目标站点限速，大面积失败。

## 六、部署

```bash
npm run build
rm -rf webdist && cp -r dist webdist
```

然后用 `workbuddy_sites_deploy`（参数见 `02_移交书` 第 7 节）。

**三个必须**：

1. `HOST=0.0.0.0`。写死 127.0.0.1 会让反向代理进不来，线上表现为 502。
2. `webdist/` 要同步，否则线上会用到旧页面。
3. 部署完验证 `/api/locals` 返回 `ready:true`。

## 七、排查清单

| 现象 | 最可能的原因 | 怎么确认 |
|---|---|---|
| 本地请求 8787 返回 502 | 走代理了 | 加 `--noproxy '*'` 重试 |
| 线上 502 | 服务绑到 127.0.0.1 | 看 `server/index.mjs` 的 `HOST` |
| 线上页面是旧的 | `webdist/` 没同步 | `grep 新文案 webdist/assets/*.js` |
| 央地传导页整页空白 | `/api/locals` 未就绪，或全部省份被判停更 | `curl /api/locals` 看 `ready` 与各 `latest` |
| 页面中文变乱码 | 地方政府站点用 GBK/GB2312 | `net.mjs` 已处理；新源要确认编码 |
| 时滞出现 +0 天 | 事务性文件被算成响应 | 看 `EXCLUDE_DOC` 是否漏了某类词 |
| 导出图比例和网页不一样 | 两处 `maxValue` 算法不同 | 两边都应是 `ceil(peak/30)*30` |
| 导出图下载不了 | 非 https 环境下剪贴板/blob 受限 | 用 `localhost` 而非局域网 IP 访问 |

## 九、如果需要给页面加导出图

照 `src/lib/exportImage.ts` 的 `drawRankChart` 抄结构：

1. 先用一个临时 canvas 的 `measureText` 量文字，算出画布该多高（脚注要换行，不量算不准）。
2. `scale = 2` 画到 2 倍尺寸 canvas，显示时缩小，字才清晰。
3. 标题区、图表区、脚注区三段式排版，`PAD` / `ROW_H` / `HEAD_H` 用常量。
4. **脚注必须带样本量和口径提醒**。只截一张没有脚注的图贴进报告，会被读成"6 个地方代表全国"。
5. 下载用 `canvas.toBlob` + `URL.createObjectURL`，**revoke 要延迟 4 秒**，立刻 revoke 会让部分浏览器的下载中断。
